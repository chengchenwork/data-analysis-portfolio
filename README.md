# 陈澄 · 数据分析作品集

经营诊断、渠道预算规划与校园空间分析。全部交互演示使用独立生成的合成数据，不代表实际业务或真实校园状态。

- `index.html`：作品集入口。
- `quant.html`：五因子经营诊断项目。
- `budget.html`：渠道预算与资金规划项目。
- `campus.html`：校园空间利用率与排课分析，中文项目说明。
- `demos/`：四个原有经营分析演示，以及 `campus/index.html` 全英文校园空间演示。
- `assets/`：本地样式与合成演示截图。

静态 HTML / CSS / JavaScript，无构建步骤、后端接口或第三方追踪。可通过 GitHub Pages 托管。原始工作数据和本地构建工具不包含在本目录中。

校园公开版使用 8 栋虚构建筑、24 间教室、两个 12 周示例学期，共 25,920 条小时记录；不是学校数据的匿名化版本。地图为原创示意图，不包含学校地图或真实建筑轮廓。数据来源声明见 `demos/campus/data/provenance.json`；第三方说明见 `demos/campus/THIRD_PARTY_NOTICES.md`。

已排课低人数时段是复核线索，不是已核实的学生缺勤；大于 150% 的读数单独列为异常，不用于正常利用率汇总。空座位时长不是实测能耗或已实现节能。计划填充率与人数/注册人数的分母不同，不能混用。

项目说明中的个人工作基于实际经历；合成指标仅用于演示交互与计算，不作为营收增长、空间节省或真实校园发现的证据。
