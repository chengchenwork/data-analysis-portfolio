# 陈澄 · 数据分析作品集

围绕经销商管理的经营诊断与渠道预算规划作品展示。全部交互演示使用独立生成的合成数据，名称、金额、费率和指标均不代表实际业务。

- `index.html`：作品集入口。
- `quant.html`：五因子经营诊断项目。
- `budget.html`：渠道预算与资金规划项目。
- `demos/`：四个可独立打开的交互演示。
- `assets/`：本地样式与合成演示截图。

静态 HTML / CSS / JavaScript，无构建步骤、后端接口或第三方追踪。可以通过 GitHub Pages 托管。演示中的数据编辑只作用于当前浏览器；原始工作数据不包含在本目录中。

历史分析与工具使用不等同于业务因果增量。项目介绍中的用途基于实际工作；网页内的合成指标仅用于说明交互与计算过程。
